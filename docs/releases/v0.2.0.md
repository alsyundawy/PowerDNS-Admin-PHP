PowerDNS-Admin-PHP **v0.2.0** is a major feature, architecture, and innovation release. It delivers automated Reverse DNS subnet tools, revision snapshot history with atomic 1-click rollback, native RFC 1035 BIND zone file parser/exporter, Dynamic DNS (DynDNS 2 protocol) support, modern DNSSEC suite (Ed25519 & RFC 7344 CDS/CDNSKEY), and strict SonarLint/PSR-12 cognitive complexity refactoring.

---

## 🌟 New Features & Major Innovations

### 1. 🧮 Interactive Subnet Calculator & rDNS Wizard (`/tools/rdns`)

- **Dual IPv4 `/24` & IPv6 `/64` Support:**
  - Real-time client-side subnet calculation and canonical zone translation.
  - IPv4 `/24` octet inversion (`192.0.2.0/24` $\rightarrow$ `2.0.192.in-addr.arpa.`).
  - IPv6 `/64` RFC 3596 16-nibble format calculation (`2001:db8:1234:5678::/64` $\rightarrow$ `8.7.6.5.4.3.2.1.8.b.d.0.1.0.0.2.ip6.arpa.`).
- **Batch PTR Record Generator:**
  - Bulk PTR record creation for host ranges using naming macros (`host-[ID].[DOMAIN]`, `ip-[IP_DASH].[DOMAIN]`, `ipv6-[HEX].[DOMAIN]`).
- **Forward-to-Reverse Scanning & Auto-PTR Sync:**
  - On-demand scanner to populate reverse zones from active forward `A` / `AAAA` records.
  - Interactive Auto-PTR toggle on the zone editor automatically synchronizing forward DNS modifications to matching reverse zones in atomic `PATCH` operations.

### 2. ⏪ Zone Snapshot History & 1-Click Atomic Rollback (`/zones/{name}/history`)

- **Automated Version Tracking:** Automatically captures zone state into `zone_snapshots` prior to every mutation, recording serial numbers, full RRsets, operator identity, and change comments.
- **Visual Revision Diff Inspection:** Intuitive UI (`views/zone_history.php`) displaying side-by-side record diffs between historical snapshots and current live zones.
- **Atomic 1-Click Rollback:** Computes the mathematical inverse delta (`DELETE` obsolete records, `REPLACE` restored records) and applies changes in a single atomic PATCH payload.
- **Pre-Rollback Safety Guard:** Automatically takes a safety snapshot before executing rollbacks to eliminate accidental data loss.

### 3. 📜 Native RFC 1035 BIND Zone Parser & Exporter

- **Zero-Dependency Native Parser:** Pure PHP parser (`parseBindZone()`) supporting RFC 1035 directives:
  - `$ORIGIN` and `$TTL` directives with duration parsing (`30m`, `2h`, `1d`, `1w`).
  - Multiline parenthesized SOA records `( ... )`.
  - Quoted string preservation and semicolon (`;`) comment stripping.
  - Blank owner inheritance from preceding records.
- **Flexible Import & Export:**
  - Upload `.zone`, `.txt`, `.db` files or paste raw BIND zone configurations in `views/zone_create.php`.
  - 1-Click BIND export button (`/zones/{name}/export`) utilizing PowerDNS native export API with fallback text generation.

### 4. 🔐 Modern DNSSEC Suite (Ed25519 & RFC 7344 CDS/CDNSKEY)

- **Cutting-Edge Cryptography:**
  - Full support for **Ed25519 (Algorithm 15, Curve25519, RFC 8080)** — fastest signing, smallest signature sizes, and lowest packet amplification risk.
  - Support for **ECDSA P-384 (Alg 14)** and **ECDSA P-256 (Alg 13)**.
- **Parent Delegation Bootstrapping (RFC 7344 & RFC 8078):**
  - 1-Click UI toggle managing `PUBLISH-CDS` (`["2"]`) and `PUBLISH-CDNSKEY` (`["1"]`) zone metadata for automatic DS record updates by supporting registries and parent TLDs.

### 5. 🌐 Dynamic DNS (DynDNS 2 Protocol) Endpoint (`/nic/update`)

- **Cross-Platform DDNS Endpoint:** Standard `/nic/update` HTTP endpoint compatible with ddclient, Mikrotik RouterOS, OpenWrt, pfSense, and inadyn.
- **Dual Authentication Modes:** Supports both HTTP Basic Authentication and Token / API Key authentication (`X-API-Key` or Bearer token).
- **Longest Suffix Zone Matching:** Automatically routes subdomains (`dyn.home.example.com`) to their deepest authoritative parent zone.
- **Standard Protocol Status Codes:** `good <ip>`, `nochg <ip>`, `nohost`, `badauth`, `notfqdn`, `badagent`, and `911`.

### 6. 🧼 Code Quality, Refactoring & Linter Eradication

- **SonarLint Cognitive Complexity Reduction:**
  - Decomposed complex routines to $\le 15$ complexity (`handleRdnsScanForward` $32 \rightarrow 4$, `normalizeBindZoneLines` $27 \rightarrow 3$, `parseBindZone` $93/45 \rightarrow 10$, `handleZoneCreate` $33 \rightarrow 4$, `handleDynDns` $53 \rightarrow 4$).
- **Function Return Limits:** Reduced return statements to $\le 3$ across `processZoneCreateSubmission`, `updateSingleDynDnsHost`, `formatBindRecordContent`, and `resolveBindRecordOwner`.
- **Modular Class Architecture:** Decomposed `PdnsClient` (25 methods $\rightarrow 18$) by extracting modules into `app/PdnsDnssecTrait.php` and `app/PdnsMetadataTrait.php`.
- **String Literal Deduplication:** Centralized literals into constants `PATH_ZONES` and `PATH_TOOLS_RDNS`.
- **PSR-12 & PSR-1 Compliance:** Separated test assertions into `tests/helper.php` (zero side-effects) and constrained all line lengths strictly $\le 120$ characters.
