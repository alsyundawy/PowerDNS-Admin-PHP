PowerDNS-Admin-PHP **v0.1.0** represents the initial production modernization and architectural overhaul of the lightweight, native PHP & PDO control plane for **PowerDNS Authoritative Server (API v1)**.

---

### 🌟 Key Highlights & Engineering Overhaul

#### 1. 📁 Standardized Web Root & Deployment Paths
- **Official Path:** Standardized web root and daemon configuration to `/var/www/PowerDNS-Admin-PHP` (migrated from `/opt`).
- **Automated Deployer:** Hardened `deploy/install-debian.sh` and production-grade `deploy/nginx.conf` virtual host with PHP-FPM socket isolation and FastCGI micro-optimizations.

#### 2. 🛡️ Enterprise Security & Defense-in-Depth
- **IDOR Remediation:** Closed Broken Object Level Authorization (IDOR) on `/api/v1/zones` where non-admin users could enumerate zones across tenant boundaries. Granular evaluation now enforces `userCanZone()`.
- **Dual-Axis Brute-Force Rate Limiting:** Rate limits login attempts against the `login_attempts` table across both client IP (max 10 failures / 15m) and targeted username (max 5 failures / 15m).
- **Session & CSRF Hardening:** Session ID regeneration (`session_regenerate_id(true)`) upon successful authentication and automated token rotation via `csrfRotate()`.
- **Cryptographic Storage:** Passwords hashed using industry-standard **Argon2id** (`PASSWORD_ARGON2ID`). PowerDNS API credentials protected via **AES-256-GCM** encryption with cryptographically random IVs.
- **Zero-CDN Architecture:** Completely eliminated external CDN dependencies (`cdn.jsdelivr.net`). Production bundles of Bootstrap 5.3.3 and jQuery 3.7.1 are hosted 100% locally in `public/assets/vendor/` with strict Content Security Policy (CSP).

#### 3. ⚡ PowerDNS Authoritative API v1 Compliance
- **Atomic RRSet Diff Engine:** Corrected RRSet deletion payload (`changetype = "DELETE"`) to comply with PowerDNS 4.7+ API standards (omitting empty `records: []` and comments).
- **cURL Deterministic Cleanup:** Wrapped cURL client handles in deterministic `try / finally` blocks to prevent socket and file descriptor leaks under high transactional concurrency.

#### 4. 📱 Modern Ergonomic UI & Mobile Responsive Optimization
- **Notch & Cutout Safe:** Integrated `viewport-fit=cover`, CSS `env(safe-area-inset-*)`, and responsive layout containers.
- **Mobile Font Stability:** Implemented `-webkit-text-size-adjust: 100%` preventing font inflation anomalies on Xiaomi, Redmi, and Poco devices (MIUI & HyperOS).
- **Table Responsiveness:** Enclosed data tables across all 14 view templates in `<div class="table-responsive">` containers for seamless horizontal scrolling.

#### 5. 🔍 Quality Assurance & Clean Code
- **Strict Typing:** Enforced `declare(strict_types=1);` across all backend PHP scripts.
- **PSR-12 Standard:** Fully compliant with PSR-12 code standards validated with PHP_CodeSniffer.
- **Static Analysis:** Zero errors across PHPStan Level 5 and Psalm Level 7.

### 📦 Installation Quick Start

```bash
# Clone repository
git clone https://github.com/alsyundawy/PowerDNS-Admin-PHP.git /var/www/PowerDNS-Admin-PHP
cd /var/www/PowerDNS-Admin-PHP

# Run automated deployment script (Debian / Ubuntu)
sudo bash deploy/install-debian.sh
```
